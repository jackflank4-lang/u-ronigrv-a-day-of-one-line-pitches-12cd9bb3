# A Day of One-Line Pitches

One sentence, 240 characters at most, that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> You have the idea and zero code, so just describe it, let an AI agent build your first app on make.fun, and if people love it, you could even win money for it.

(159 characters.)

## How it works

`main.ts` (Node 22, stdlib only) writes the sentence to `/output/entry.txt`:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
